# Topic Recap Skill

## When to use this
Use this skill when the user wants to summarize the chat, save their learnings, or create a recap file.

## What to do
Follow these steps:

1. **Pick the topics:** Look at the chat history. If we talked about different things (like Git and Linux), treat them as separate topics so they get their own files.
2. **Clean the data:** Remove any sensitive information before you write. Change real domain names, IP addresses, or URLs to generic ones like example.com. Delete passwords, API keys, and secret credentials. Make the notes safe to share publicly.
3. **Format the notes:** Use the template below to create a summary for each topic. Keep the language simple and human readable.
4. **Save the files:** Save each topic as its own markdown file in the current folder. Name them simply, like git-reset-recap.md or linux-cron-recap.md.

## Template to use
Always use this exact structure for the notes:

# [Topic Name] Recap
**Date:** [Current Date]

## Overview
[Write 2 or 3 sentences explaining what this is and why we discussed it.]

## Key Concepts
* **[Concept 1]:** [Simple explanation of how it works]
* **[Concept 2]:** [Simple explanation]

## Commands
[Add commands or code snippets we used. Include short comments explaining what they do. Make sure there are no real domains or secrets here.]

## Watch Out For
[What could go wrong? What should the user avoid doing?]

## Interview and Future Reference
[Why is this important? How would you explain it in an interview? What is the main thing to remember for next time?]
